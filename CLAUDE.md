# Melody: notes for Claude

- The live app is the Google Sheets edition: `docs/index.html` (served by GitHub Pages from the branch `claude/household-task-app-mfl3pq`) and `google-sheets/Code.gs` + `Parser.gs` (sent to Apps Script with `npm run gas:deploy -- "what changed"`, or pasted by hand; see `google-sheets/README.md`, "Deploying with clasp"). Work on a new branch and open a pull request.
- The household is **Nas** and **Sandi**. Use these names in examples, mockups and test data.
- Look and feel follows `docs/design/hearth.md`. The previous look is recorded in `docs/design/style-original-green.md`.
- Ideas go in `BACKLOG.md`. Whenever something runs into a limit of the web app (iOS Safari, home-screen apps, Apps Script), tag the backlog item **Native only** or **Better native** and say the limit in one line. See "Native app tags" at the top of the backlog.
- Shared skills are installed in this repo under `.claude/skills/`, copied from `nasermutawi/claude-skills` (the master copy; see its README for what each skill does). They load automatically. For any UI or UX work, use **ui-ux-pro-max** alongside `docs/design/hearth.md`; Hearth wins where they disagree. To update them, copy the folders again from `claude-skills` and note the commit in `.claude/skills/SOURCE.md`; change skills there, not here.
- After changing `Code.gs` or `Parser.gs`, deploy with `npm run gas:deploy -- "what changed"` (try `--dry-run` first) when `google-sheets/.clasp-ids.json` and a clasp login exist on this computer. Otherwise tell the user to paste and redeploy by hand. Never commit `.clasp-ids.json`, `.clasp.json` or `.clasprc.json`.
